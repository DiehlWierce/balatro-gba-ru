# Бюджет памяти

Отчёт снимается после каждой волны: `python3 ru-tools/memory_report.py` (после сборки рома).
Пулы объектов (`include/def_balatro_mempool.h`) показывает `scripts/get_memory_map.sh build/balatro-gba.elf`.

IWRAM — самая тесная память: в ней лежат `.iwram`, `.bss`, `.data` и стек. Новые изменяемые
глобальные данные размером больше нескольких десятков байт кладутся в EWRAM
(`EWRAM_BSS`/`EWRAM_DATA` из tonc или `POOL_ENTRY(..., EWRAM)`), таблицы — `static const` (ROM).

Пулы объектов (`scripts/get_memory_map.sh build/balatro-gba.elf`, всего 9780 байт):

| Пул | Размер, байт | Память |
|---|---|---|

| `ListNode` | 1536 | EWRAM |

| `Joker` | 192 | EWRAM |
| `BoosterPackObject` | 128 | EWRAM |
| `VoucherObject` | 128 | EWRAM |

Заметки:

- `Card` ровно 8 байт (`suit`, `rank`, `enhancement`, `seal`, `debuffed`, `face_down`,
  `played_ante`, `bonus_chips`), это проверяет `_Static_assert` в `include/card_rules.h`.
  Новое поле в `Card` увеличит пул на 128 байт на каждый байт структуры.
- Таблицы Таро, ваучеров, джокеров (`joker_registry`) и анте (`ante_table.h`) — `static const`, то есть ROM.
- В IWRAM остались пулы `Sprite` и `CardObject`: их читают обработчики экрана. Кандидатов на перенос
  в EWRAM нет.
- Спрайты: 68 записей OAM из 128 (см. `PALETTES.md`), тайлов 896 из 1024.

## После изданий (ветка `claude/editions`)

IWRAM 27640 из 32768 (84.3%, +8 байт к слиянию волн 1–3), EWRAM 5516 + 2048 (`.sbss`). Новых
изменяемых данных нет: поле `Joker.edition` лежит в выравнивании структуры, `Card.edition` в битах
рядом с флагами, `Card` остаётся 8 байт (пул 1024). Пул `Joker` 192 байта.
