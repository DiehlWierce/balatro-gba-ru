## Известные замечания

- Бесконечный режим (простой вариант, ветка `endless-bugfix-2`): после победы над боссом 8-го анте и «Забрать»
  экран победы предлагает «Дальше» (лавка, анте 9 из 12) или «В меню»; требования анте 9–12 как в оригинале
  (`include/ante_table.h`, хост-тест `tests/ante_table`), считаются в 64 бит и насыщаются на `UINT32_MAX`
  (единственный такой случай: Стена на анте 12 на Фиолетовой/Золотой ставке). Победа над боссом 12-го анте
  завершает игру («Заново»/«В меню»). Сценарий `endless.txt`. Не сделан полный вариант («мантисса + экспонента»).
  Победа над 8-м анте не сохраняет счётчик «сыграно» отдельно: «Частая» на экране победы по-прежнему считает
  Роял-флеш отдельной рукой.
- Боссы: у Колокола короткая подпись «ВЫБОР 1» не видна в раунде (карта всегда выбрана, на её месте
  название комбинации); полная подпись есть на экране выбора блайнда. Описание джокера в раунде
  недоступно (только в лавке), для закрытого жёлудем джокера оно скрыто («???»).
- Память: IWRAM занята на 84% (EWRAM 2.8%, ROM 15%; свободных кандидатов нет: s_bgaff_arr читается в HBlank), новые изменяемые данные класть в EWRAM.

## Как продолжить

```bash
git fetch origin
git checkout claude/gracious-hamilton-o04bdi
# если демон Docker не запущен:
nohup setsid dockerd > /tmp/dockerd.log 2>&1 < /dev/null &
docker compose run --rm gbalatro        # сборка рома
python3 ru-tools/emu/run.py ru-tools/emu/scenarios/smoke_shop.txt /tmp/shots
```

Образ `gbalatro:dev` собирался локально поверх `devkitpro/devkitarm:latest`: Docker Hub отдавал 429,
образ тянули через `mirror.gcr.io`. В образе нужен Pillow (Python 3.11).

## A7 Таро (ветка `a7-tarot`)

Готово: 21 из 22 Таро как расходники (`ITEM_TYPE_CONSUMABLE`, `CONSUMABLE_TYPE_TAROT`, `enum TarotType` в
`include/tarot_rules.h`): Дурак, Маг, Жрица, Императрица, Император, Иерофант, Влюблённые, Колесница,
Справедливость, Отшельник, Сила, Повешенный, Смерть, Умеренность, Дьявол, Башня, Звезда, Луна, Солнце,
Суд, Мир. Режим выбора цели: выбрать карты в руке (A), подняться в ряд расходников и нажать A; без нужного
числа карт Таро дрожит и не срабатывает. Фиолетовая печать создаёт Таро при сбросе (при свободном слоте),
в лавке Таро выпадает так же часто, как Планета, бустер Аркана работает (взятое Таро идёт в ряд
расходников, без слота пропадает: в оригинале оно сразу применяется к картам). Свои `RngSequence`:
`SHOP_CONSUMABLE_TYPE`, `SHOP_TAROT`, `TAROT_CREATE`, `TAROT_PURPLE_SEAL`, `PACK_TAROT`, `TAROT_JUDGEMENT`.
Хост-тест `tests/tarot_rules`. Сценарии `tarot.txt`, `tarot_shop.txt`, `purple_seal.txt`
(`make DEBUG_TAROT=1` для выдачи Таро через `g_debug_give_tarot`).

Не готово: Колесо фортуны (нужны издания, в игре нет), описание Таро в раунде (в раунде описания
показываются только в лавке), Таро в бустере Аркана не применяется сразу и не показывает описание,
Торговец Таро (ваучер) не меняет шанс Таро в лавке, спрайты Таро — первый набросок (цифра и символ).
Память: IWRAM без изменений (изменяемых данных почти нет), `MAX_ACTIVE_CONSUMABLES` 6 → 9.
