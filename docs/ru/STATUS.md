- Колода в правом нижнем углу раунда всегда красная: она нарисована в `background_gfx.png` (A10).
- Строка «Фиолетовая ставка» упирается в стрелки L/R.
- У наклеек джокеров (ставки) нет значка на спрайте, только строка в описании.
- «Забрать» может уйти в минус при нескольких арендованных джокерах.
- Боссы: Крюк сбрасывает после подсчёта; у Янтарного жёлудя рубашкой вверх виден реальный текст
  описания; у Колокола не показывается короткая подпись.
- Память: IWRAM занята примерно на 85%, новые изменяемые данные класть в EWRAM.

## Как продолжить

```bash
git fetch origin
git checkout claude/gracious-hamilton-o04bdi
# если демон Docker не запущен:
nohup setsid dockerd > /tmp/dockerd.log 2>&1 < /dev/null &
docker compose run --rm gbalatro        # сборка рома
python3 ru-tools/emu/run.py ru-tools/emu/scenarios/smoke_shop.txt /tmp/shots
```

Образ `gbalatro:dev` собирался локально поверх `devkitpro/devkitarm:latest`: Docker Hub отдавал 429,
образ тянули через `mirror.gcr.io`. В образе нужен Pillow (Python 3.11).
