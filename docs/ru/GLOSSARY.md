# Глоссарий русской сборки

Единые термины для всех строк в коде и надписей в графике. Шрифт моноширинный 8×8: одна буква — один тайл, поэтому длина строки ограничена числом тайлов в рамке. Строки пишутся в исходниках в UTF-8 и компилируются в CP1251 (один байт на символ). Поэтому `strlen()` и ширина в символах совпадают, если не используются `Ё/ё` — они тоже однобайтовые.

## Правила написания

- Числа и валюта: `$4`, `+30`, `X1.5` — как в оригинале, знак доллара перед числом.
- Цвета в описаниях: красный — множитель, синий — фишки, жёлтый — деньги и названия комбинаций, зелёный — вероятности («1 из 2»).
- Описание джокера: «Сыгранные карты масти Червы дают +3 множ. при подсчёте». Глаголы — во множественном числе для карт, «даёт» для одной карты.
- Буква «ё» пишется везде, где она есть в слове: «подсчёте», «даёт», «Зелёная».
- Сокращения только из этой таблицы. Новое сокращение сначала добавляется сюда.
