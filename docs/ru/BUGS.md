# Аудит v0.4.1-ru относительно апстрима v0.2.3 и оригинальной Balatro

Аудит только записывает найденное, исходники не правились. Известное из `STATUS.md` («Известные
замечания», «Не сделано и вынесено за релиз») и `ROADMAP.md` (Splash, кап Мима, бустеры в общем ряду
лавки, Мим и Золотые карты в конце раунда) сюда повторно не заносится. Отличия, которые вынуждает
железо GBA, помечены «ограничение».

### Об эталоне

Balatro 1.1 по найденным источникам **не вышла**: последняя сборка 1.0.1o, 1.1 только анонсирована
(новые джокеры, ваучер, переделка Синей ставки). Официальные патчноуты Steam веб-агент не открыл
(только пересказы в новостях). Поэтому значения ниже взяты с balatrowiki.org (21 страница) и помечены
«1.0.x (вики)». Если 1.1 выйдет и поменяет баланс, пункты с этой пометкой нужно перепроверить.

### Что проверено

- Сборка (Docker, `make`) и все хост-тесты `tests/run_tests.sh`: зелёные.
- 19 прогонов сценариев эмулятора без отладочной сборки (smoke_shop, smoke_lose, decks, decks_plasma,
  black_deck_six_jokers, stakes, stake_stickers, modifiers, purple_seal, planets, endless,
  decks_new deck=6..13): все до конца, просмотрено около 45 кадров.
- Код по 8 областям: джокеры ID 0–93, джокеры ID 94+ и реестр, боссы/ставки/конец забега,
  лавка/экономика/теги, расходники/бустеры/уровни рук, издания/ваучеры/улучшения/колоды, ядро раунда
  (round.c, hand.c), графика/текст/спрайты/сохранение.
- Сверка 23 механик с вики (таблица в конце).
- На ROM с отладочной сборкой: Burnt Joker (`audit_burnt.txt`), Blueprint + Steel Joker
  (`audit_blueprint_steel.txt`).
- Коммиты «по памяти» из v0.4.0-ru..v0.4.1-ru:
  - формула скидок совпадает с вики («half down», минимум $1);
  - Bloodstone Uncommon верно, а **Campfire должен быть Rare** (B-021);
  - Obelisk вики однозначно не подтверждает (B-058);
  - шансы изданий у джокеров верны, у игральных карт вдвое ниже (B-007). Negative при Hone/Glow Up не подтверждён;
  - Колесо с «Ой, все шестёрки» и перевыбранный босс как использованный (64c49e3) совпадают с вики.

### Что не проверено

- Сценарии с отладочной сборкой из `ru-tools/emu/scenarios` (boss_*, tarot*, spectral*, jokers_*,
  editions, wheel, packs) в этот раз не прогонялись.
- Из находок кода на ROM проверены только B-001 и B-002. Остальное подтверждено по коду или кадрам.
- Реальное железо (SRAM, тайминги) и производительность при 6+ джокерах.
- Апстрим `8dee4b7` (Sprite Containers) не влит и не разбирался.
- Не разбирались: ширина описаний джокеров 94+, путь `item_acquire` для всех типов предметов,
  `tag_process_sm` при выходе в меню, Полихром при нескольких ретриггерах, Взломщик (Burglar),
  место Плазменной колоды относительно джокеров в подсчёте.

### Апстрим после v0.2.3

Из 24 коммитов влит 21. Не влиты `6413d43`, `8dee4b7` и `10ebba7`. `6413d43` у нас никакой баг не
чинит, а если влить его без правок, сломаются экран победы и переход в бесконечный режим: `current_blind`
сбросится раньше `game_over_common_init`, а `shop_on_exit` продвинет блайнд второй раз. При слиянии
`increment_blind()` в `round_end` нужно вызывать только при `win_pending == false`. Сохранение
(`save_game`, апстрим `f2fc8c9`) из нашего кода нигде не вызывается.
